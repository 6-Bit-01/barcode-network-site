# Wheel audio assets

This folder contains the verified local wheel ceremony audio used by the live overlay.

- Numeric MP3 files are the selectable wheel-spin music pool. `32 (1).mp3` is referenced from code as `/audio/wheel/32%20(1).mp3`.
- `WheelCheer.mp3` and `WheelEncrypt.mp3` are ceremony sound effects only and are not part of the random spin pool.
- Do not hotlink audio from external sites for live wheel playback.
