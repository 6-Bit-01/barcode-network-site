Mac's approved hat is **black with a red MODEM wordmark**. Preserve his white
makeup, red forehead arcs, reddish beard/braids and tattooed arms. Cache's cap,
glasses, mask, headphones and Greek-key costume trim match the bridge. The car
uses its approved rear view and central emblem. No pursuer identity, new villain,
Sheila depiction or wider resolution is added.

The source PNGs in `sources/` are untouched built-in ImageGen results. Runtime
WebPs are quality 92, method 6 format conversions with no crop, resize, repaint
or compositing. `generation-prompts.json` contains every complete prompt and
reference path. `art-manifest.json` records selected outputs, reference hashes,
source/runtime dimensions and SHA-256 values. All four selected outputs were
visually reviewed for character identity, hands, physical separation and logos.

These are static illustrations. Runtime owns dialogue, title, status and control
text. Scene 4 is a different location from Cache's receiver; describe the cut in
the transcript, with dialogue continuing on the crew's comms.
