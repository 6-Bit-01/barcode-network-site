# Cache beat hardware and energy

Three original ImageGen paintings form one weathered teal-metal visual system.
They are new sibling assets; existing canonical artwork is untouched.

| Sheet | Frames | Meaning |
| --- | --- | --- |
| Hardware | 0–3 / 4–7 | Dormant / engaged mint chevron, coral hexagon, cyan shield, amber square |
| Energy | 0–3 / 4–7 / 8–11 | Conductive runways / hollow impact rings / shard clusters, same action colors |
| Timing | 0–3 / 4–7 | Dormant, charging, ONE, release sockets / Good, Perfect, Miss, streak housings |

Prompts and original transparent PNGs are preserved beside the runtime WebP
atlases. `python3 tools/pack-cache-beat-art.py` reproduces lossless packing.
Authored row gutters isolate complete forms before uniform transparent padding;
no source pixels are recolored, resized or painted over. The packer verifies
exact decoded RGBA and records source/cell hashes and draw crops in `packing.json`.
Energy and timing use per-frame draw crops; live button symbols, countdowns,
judgments and actual adrenaline gains remain sharp and preference aware.

The shared image cache loads each atlas once, from an immutable published commit
with its bundled path as one fallback. Road surfaces use the existing projection;
FX read existing simulation phase and accepted receipt age. These are painted
beveled forms in a perspective Canvas world, not additional 3D engine geometry.
