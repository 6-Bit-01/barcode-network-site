# Cache Back mirror expression sheet

`cache-back-mirror-expressions.webp` is a 3 × 2 atlas of six 512 × 512 cells.
Reading order: calm, focused, Turbo/Zone, close pass, collision, low signal.
The source PNG is kept under `sources/`.

The original art was generated from the owner's Cache Back model
`openart-image_sUa578AT_1765587750737_raw(1).png`. Its visible half is retained
in each cell, with the missing half completed in the same six-frame sheet.
Cache has two brown eyes looking ahead in the ordinary states. The collision
cell (bottom center) shows both eyes squeezed shut and a slight head jolt.
The yellow cap, black glasses and angular mask remain the same character art.
The model reference stays in the owner's files rather than being copied here.

The source and runtime atlas are transparent outside the portrait. The runtime
crops the eye/upper-mask band and draws the face solid inside the mirror clip;
shared glare still passes over it. The decorative road remains visible around
the portrait and never communicates actual traffic danger.
