# Level 1 Signal Discharge and Signal Amp

Custom transparent artwork generated with OpenAI ImageGen for the October 2026
Level 1 presentation pass. The references were the existing weathered comic art:
the prepared Broadcast Jammer and 6 Bit sprites, `boss-pulse.webp`, and the
painted broadcast terminal. No existing canonical sprite sheet was modified.

| Sheet | Cels | Playback | Purpose |
| --- | --- | --- | --- |
| `signal-discharge-atlas.webp` | 4×2; 444×444 per cel | Warning: 175 ms per cel; active: four cels across the existing 420 ms Jammer / 360 ms SLAM lifetime | First row is a hollow amber warning; second row is active electrical discharge. |
| `signal-amp-atlas.webp` | 4×2; 444×444 per cel | 140 ms per cel from the existing combat FX clock | Weathered purple portable amp, animated speaker and electricity. |

`*-source.png` files retain the exact original generated bytes. Sources were
1774×887; the packing tool crops the fixed 4×2 grid and adds at most one pixel
of transparent padding to make uniform 444×444 cells. It neither resamples nor
changes source color or alpha. WebP encoding is lossless with exact RGBA
verification; `packing.json` records source/atlas SHA-256 hashes, cel crops,
source pixel hashes and alpha bounds. Regenerate the atlases with
`tools/pack-level1-signal-art.py --signal <source> --amp <source>`.

The original generated sources were:

- Signal: `exec-2da36c41-9356-4508-a5f1-121af43bcd3e.png`
- Amp: `exec-caebbd94-0b8a-42a9-a0cf-30d3e9d2a8d0.png`

`src/game/level1-signal-art.js` uses the existing PresentationAssets cache. The
Jammer and SLAM owners supply their existing simulation clocks and exact danger
rectangles. Painted electricity is clipped to those rectangles; warning alpha
is 0.80 and active alpha is 0.54 so the hero remains readable and discharge is
clearly more present than the hollow warning. Precise corner
guides and the existing phase labels remain visible. Damage, timing and audio
stay with their existing owners. Reduced motion or disabled flashes hold
warning cel 0, active cel 4 and amp cel 0. The amp's three small charge sockets
are drawn from the real remaining charge count over the artwork.
